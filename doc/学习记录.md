今天 git 操作的顺序:
1. 解压并用VsCode打开文件夹
3. 增删数字
5. 创建分支并合并
7. 添加远程库并保存

| 命令 | 作用 | 什么时候用|
|:----:|:----:|:----:|
|git checkout -b feature-blink|创建分支|进行新功能开发而不想影响主代码时|
|git checkout main|返回主干|分支编程结束或者查看更改主干时|
|git merge feature-blink|合并|将新编好的分支与主干合并|
|git log --oneline <br> git reset --hard HEAD~1|撤回上一次提交|重做、修改代码时|
|git push -u origin main|存入库|在项目结束后，将工程文件导入远程库中以保存或共享|
